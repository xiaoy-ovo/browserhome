一个美观实用的浏览器启动页，替代传统新标签页。

功能特性

搜索
大号居中搜索框，支持百度与 Google 搜索引擎一键切换
输入内容后回车即可跳转搜索

信息展示
实时显示当前时间
实时天气信息展示
随机展示一句名言

快速链接
可自定义添加常用网站
支持拖拽排序，自由调整位置
数据自动保存

主题与外观
深色模式与浅色模式一键切换
背景图片随机切换，图片来源于 Unsplash
液态玻璃效果，呈现磨砂半透明质感
流畅的过渡动画

数据存储
所有设置与数据均存储在浏览器本地
无需登录，无需后端服务

技术栈

HTML / CSS / JavaScript
纯前端实现，无框架依赖
使用 LocalStorage 进行数据持久化
天气数据通过 API 获取
背景图片通过 Unsplash API 获取

使用方法

克隆仓库到本地
用浏览器直接把此文件变成新标签页 startup.html(路径) 即可使用
在浏览器中设置为新标签页需要请在设置设置

自定义天气 API

可使用特殊方法自定义您认为准确的天气 API
